# AI Resume Screening System

## Project Overview

The AI Resume Screening System is a Python-based
application that analyzes resumes against job descriptions.

It extracts resume text, identifies technical skills,
calculates similarity scores, and ranks candidates.

## Technologies

- Python
- Streamlit
- NLP
- Scikit-learn
- TF-IDF
- Cosine Similarity
- PyMuPDF
- Pandas

## Features

- Upload multiple PDF resumes
- Extract text from PDF files
- Identify technical skills
- Compare resumes with job descriptions
- Calculate matching scores
- Rank candidates
- Download results as CSV

## Installation

1. Clone the repository.

2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## Disclaimer

The matching score is an automated text and skill
matching indicator. It is not a hiring recommendation
or a measure of candidate quality.
